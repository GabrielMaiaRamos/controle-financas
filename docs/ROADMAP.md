# Roadmap — Cultural Notes

Este documento descreve a evolução planejada do projeto, dividida em fases
Cada fase representa um bloco de aprendizado e um entregável concreto.

```markdown

## Fase 1 — Fundamentos Web (Atual)
**Objetivo:** Dominar a base do desenvolvimento web.
- [x] Estrutura HTML semântica
- [x] Estilização com CSS
- [ ] Interatividade com JavaScript
- [ ] Responsividade (mobile-first)

**Entregável:** Página funcional e responsiva.

## Fase 2 — Interatividade e Persistência
**Objetivo:** Tornar a aplicação dinâmica.
- [ ] Manipulação avançada do DOM
- [ ] Eventos e formulários
- [ ] LocalStorage para persistir notas
- [ ] Filtros e busca

**Entregável:** Aplicação que salva e recupera notas localmente.

## Fase 3 — Modernização com Framework
**Objetivo:** Utilizar um framework moderno.
- [ ] Migrar para React ou Next.js
- [ ] Componentização
- [ ] Gerenciamento de estado
- [ ] Consumo de API

**Entregável:** Aplicação reescrita com framework, mais escalável.

## Fase 4 — Backend e Banco de Dados
**Objetivo:** Dar autonomia total à aplicação.
- [ ] API com Node.js ou Python (FastAPI)
- [ ] Banco de dados (PostgreSQL ou SQLite)
- [ ] Autenticação de usuário
- [ ] Deploy (Vercel, Railway, Render)

**Entregável:** Aplicação full-stack com backend e banco de dados.

## Fase 5 — IA para Recomendações
**Objetivo:** Adicionar inteligência ao sistema.
- [ ] Embeddings de notas e reviews
- [ ] Banco de dados vetorial (ChromaDB ou pgvector)
- [ ] Sistema RAG para buscar notas similares
- [ ] Recomendações personalizadas com LLM

**Entregável:** Sistema que sugere álbuns, músicas e livros com base no meu acervo.
