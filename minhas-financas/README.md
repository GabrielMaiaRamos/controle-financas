# Controle Financas

Aplicacao React principal do projeto de controle financeiro pessoal.

## Estado atual

- Registro de gastos, entradas e planos
- Remocao de lancamentos
- Persistencia local com `localStorage`
- Interface responsiva

## Comandos

```bash
npm install
npm run dev
npm run lint
npm run build
```

A documentacao geral esta em [../README.md](../README.md) e o planejamento completo esta em [../docs/ROADMAP.md](../docs/ROADMAP.md).
